# Flask Mongo

Flask Mongo es una aplicación simple que utiliza Flask como framework web y MongoDB como base de datos para almacenar y gestionar datos de forma eficiente.

## Características

- Interfaz web ligera y rápida con Flask.
- Conexión y manejo de datos con MongoDB.
- Operaciones básicas de CRUD (Crear, Leer, Actualizar, Eliminar).
- Fácil de configurar y extender.

## Requisitos

- Python 3.7 o superior
- Flask
- PyMongo (cliente oficial de MongoDB para Python)
- MongoDB (servidor local o remoto)
